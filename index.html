01 · Presentación

Conoce TechStore MTY

TechStore MTY es un repositorio digital académico que reúne información de seis productos tecnológicos. El contenido se organiza en categorías y se presenta mediante fichas, una tabla de datos y recursos de consulta para facilitar la localización y comprensión de la información.

Misión

Organizar y presentar información de productos tecnológicos de manera clara, uniforme y accesible, utilizando recursos digitales que faciliten su consulta.

Visión

Consolidar un espacio digital ordenado y funcional que muestre cómo la clasificación y el uso adecuado de herramientas web ayudan a compartir información.

Objetivo

Integrar un catálogo de seis productos, clasificarlos por función, estructurar sus datos y ofrecer recursos digitales complementarios en una página de navegación sencilla.

¿Qué contiene el repositorio?

• Presentación del proyecto y sus objetivos.

• Cuatro categorías de productos.

• Catálogo con búsqueda y filtros.

• Base de datos con nueve campos.

• Recursos de texto y video.

• Glosario de conceptos digitales.

06 · Términos y conceptos

Glosario digital

Conceptos esenciales para comprender cómo se estructura, publica y utiliza un repositorio en internet.

Repositorio digital

Espacio organizado que reúne recursos e información en formato digital para facilitar su almacenamiento, consulta y distribución.

Sitio web

Conjunto de páginas relacionadas que se encuentran disponibles en internet bajo una misma dirección o dominio.

Página web

Documento digital que puede contener texto, imágenes, enlaces, audio y video, y que se visualiza mediante un navegador.

HTML

Lenguaje de marcado que define la estructura y organización del contenido de una página web.

CSS

Lenguaje de estilos utilizado para definir la presentación visual, como colores, tipografías, espacios y distribución.

JavaScript

Lenguaje de programación que permite agregar interactividad y comportamientos dinámicos a una página web.

URL

Dirección que permite localizar un recurso, documento o página dentro de internet.

Dominio

Nombre legible que identifica la dirección de un sitio web y facilita que los usuarios lo encuentren.

Hosting

Servicio que almacena los archivos de un sitio web y permite que estén disponibles en internet.

Base de datos

Conjunto organizado de información que permite registrar, consultar, actualizar y administrar datos.

Interfaz de usuario (UI)

Parte visual de una plataforma con la que interactúa el usuario mediante menús, botones, campos y controles.

Experiencia de usuario (UX)

Percepción y experiencia general de una persona al utilizar un sitio web o una aplicación.

Hipervínculo

Elemento que permite navegar hacia otra página, documento o recurso mediante un enlace.

Multimedia

Integración de distintos formatos de información, como texto, imágenes, audio, animación y video.

Diseño responsivo

Técnica que adapta la presentación de una página web a diferentes tamaños de pantalla y dispositivos.

Navegador web

Programa que permite acceder, interpretar y visualizar páginas y contenidos disponibles en internet.

Accesibilidad web

Prácticas de diseño y desarrollo que buscan que los contenidos digitales puedan ser utilizados por la mayor diversidad de personas.

Motor de búsqueda

Servicio que ayuda a localizar información en internet a partir de palabras o frases ingresadas por el usuario.
